# Third-party notices

Worsaga depends on third-party open-source software.

Notable dependencies:

- PyMuPDF / MuPDF for PDF processing. PyMuPDF is available under AGPL or
  commercial licence terms.
- Rich for terminal output.
- platformdirs for platform-native config paths.
- MCP Python SDK when the `mcp` extra is installed.
- PyYAML when the `yaml` extra is installed.

See `pyproject.toml` for the current dependency list.
